Welcome to Authors Haven API

A social platform for the creative at heart. Our GraphQL API enables you to build applications that connect authors and foster inspiration and innovation through modern web technologies.

Quick Start

The Authors Haven API is a GraphQL endpoint that allows you to:

  • Create and manage user accounts
  • Query user information
  • Build social features for authors

API Endpoint

POST /graphql

Send your GraphQL queries and mutations to this endpoint.

API Examples

Creating a User

mutation {
  createUser(
    firstname: "John",
    lastname: "Doe", 
    username: "johndoe",
    email: "john@example.com",
    password: "securepassword"
  ) {
    firstname
    lastname
    username
    email
  }
}

Getting All Users

{
  allUsers {
    id
    firstname
    lastname
    username
    email
  }
}

Getting Started

  1. Set up your environment: You'll need a GraphQL client to interact with our API
  2. Explore the schema: Use GraphiQL or another GraphQL explorer to understand available queries and mutations
  3. Authentication: Follow our authentication guide to secure your requests
  4. Build your app: Start creating amazing experiences for authors!

Deployment Information

Important Note

While this documentation is hosted on GitHub Pages, the actual Authors Haven API requires a server environment with:

  • Ruby on Rails runtime
  • PostgreSQL database
  • Application server (Puma)

Consider deploying the API to platforms like:

  • Heroku
  • Railway
  • DigitalOcean App Platform
  • AWS Elastic Beanstalk
  • Google Cloud Run
